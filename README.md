# LawCodex/.github

Organisation profile and shared conventions for [LawCodex](https://github.com/LawCodex).

- `profile/README.md` — the organisation page, generated by `scripts/build_profile.py` from
  `scripts/countries.tsv` and `scripts/status.tsv` (requires an authenticated `gh` CLI).
- `CONVENTIONS.md` — format and sourcing rules followed by every repository.
